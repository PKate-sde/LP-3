## 4. Theory

A smart contract is a computer program stored on a blockchain. It executes automatically when a user interacts with it.

Solidity is a programming language used to create smart contracts on the Ethereum blockchain.

In this experiment, we create a Student Data smart contract to store and manage student information.

The contract uses the following Solidity constructs:

### A. Structures (struct)

A structure is used to group different types of information into a single record.

In this program, the Student structure stores:
- Student ID
- Student Name
- Student Age
- Student Course

### B. Arrays

An array is used to store multiple student records in one variable.

In this experiment, a dynamic array stores the details of multiple students.

### C. Fallback Function

A fallback function is a special function that executes when a call does not match any existing function in the smart contract, or when unmatched data is sent to the contract.

It is declared using the `fallback()` keyword.

### D. Receive Function

The receive function is a special payable function that executes when ETH is sent directly to a contract without any additional data.

It is declared using the `receive()` keyword.

### E. Gas and Transaction Fee

Gas is the unit used to measure the computational work required to execute operations on Ethereum.

The transaction fee is calculated using:

**Transaction Fee = Gas Used × Effective Gas Price**

## 5. Solidity Program

File name: `StudentData.sol`

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract StudentData {

    // Structure to store student information
    struct Student {
        uint id;
        string name;
        uint age;
        string course;
    }

    // Array to store multiple students
    Student[] public students;

    // Variables for fallback testing
    uint public fallbackCalls;
    uint public fallbackBalance;

    // Function to add student details
    function addStudent(
        uint _id,
        string memory _name,
        uint _age,
        string memory _course
    ) public {
        students.push(Student(_id, _name, _age, _course));
    }

    // Function to get student details using index
    function getStudent(uint _index)
        public
        view
        returns (uint, string memory, uint, string memory)
    {
        require(_index < students.length, "Student does not exist");

        Student memory s = students[_index];

        return (s.id, s.name, s.age, s.course);
    }

    // Function to get total number of students
    function getStudentCount() public view returns (uint) {
        return students.length;
    }

    // Receive ETH directly
    receive() external payable {
        fallbackBalance += msg.value;
    }

    // Fallback function
    fallback() external payable {
        fallbackCalls++;
        fallbackBalance += msg.value;
    }
}
```

## 6. Explanation of the Program

**1. `pragma solidity ^0.8.20;`**

Specifies the Solidity compiler version.

**2. `contract StudentData`**

Creates a smart contract named StudentData.

**3. `struct Student`**

Defines a structure containing student ID, name, age and course.

**4. `Student[] public students`**

Creates a dynamic array to store student records.

**5. `addStudent()`**

Adds new student information to the array using the `push()` function.

**6. `getStudent()`**

Displays student details using the array index. Indexing starts from zero.

**7. `getStudentCount()`**

Returns the total number of students stored in the array.

**8. `receive()`**

Accepts ETH sent directly to the contract without transaction data and updates the fallback balance.

**9. `fallback()`**

Handles unmatched function calls and updates the fallback call counter and balance.

## 7. Implementation Steps

### Step 1: Open Remix IDE

1. Open https://remix.ethereum.org/
2. Open the File Explorer.
3. Create a new file named `StudentData.sol`.
4. Paste the Solidity program into the file.

### Step 2: Compile the Program

1. Open the Solidity Compiler tab.
2. Select compiler version 0.8.20.
3. Click Compile StudentData.sol.
4. Check that the program compiles successfully.

### Step 3: Configure MetaMask

1. Install MetaMask from https://metamask.io/
2. Create a wallet.
3. Enable test networks.
4. Select Ethereum Sepolia.
5. Obtain free Sepolia ETH using a faucet.
6. Check that the test ETH is available in your wallet.

### Step 4: Deploy the Smart Contract

1. Open Deploy & Run Transactions in Remix.
2. Select Browser Extension as the environment.
3. Connect MetaMask.
4. Ensure that the selected network is Sepolia.
5. Select StudentData from the contract dropdown.
6. Keep the Value field at 0 wei.
7. Click Deploy.
8. Confirm the transaction in MetaMask.
9. Wait for successful deployment.

The deployed contract will appear under Deployed Contracts.

### Step 5: Add Student Records

### Step 7: Test the Receive Function

1. Set the Value field to `1000000000000`.
2. Select `wei`.
3. Copy your deployed StudentData contract address.
4. Open MetaMask and send `0.000001 ETH` directly to the contract address.
5. Leave the transaction data empty.
6. Confirm the transaction.

Check the following functions:

- `fallbackCalls()` should return `0`.
- `fallbackBalance()` should return `1000000000000`.

This confirms that the receive function executed successfully.

### Step 8: Test the Fallback Function

To trigger the actual fallback function, send a transaction containing non-empty, unmatched data.

1. Open Remix's low-level interaction feature.
2. Enter the deployed contract address.
3. Enter the calldata:

```text
0x12345678
```

4. Set the Value field to `2000000000000 wei`.
5. Click Transact.
6. Confirm the transaction in MetaMask.

This triggers the fallback function because the supplied data does not match any existing function.
